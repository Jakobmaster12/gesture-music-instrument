# Eigene Sounds

Hier kommen eigene WAV Dateien rein, ein Unterordner pro Klang ist nur
eine Empfehlung zur Ordnung - Namen und Ablage sind frei.

Damit eine Datei tatsaechlich benutzt wird, muss sie zusaetzlich in
`src/audio/sample_files.py` eingetragen werden. Dort steht auch die
vollstaendige Anleitung und die Liste der Bank Namen (kick, clap, hats,
sub, acid, lead, stab, sweep, ...).
